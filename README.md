## Method Overview
CamoDreamer proposes a context-decoupled assimilation framework for high-fidelity camouflage image generation (CIG), which focuses on generating visually concealed objects that seamlessly blend into the background. This framework effectively separates object and background cues to enhance realism and consistency, outperforming existing methods in fidelity and perceptual quality. This paper aims to address the following issues:
**Key challenges**: **(1) Background artifacts**: Existing methods often produce unrealistic backgrounds with severe texture artifacts; **(2) Appearance discrepancy**: There is a clear visual inconsistency between foreground objects and the background, leading to color mismatches.

## 1.Installation
We recommend using Python 3.8.0 and PyTorch with CUDA support. To set up the conda environment:
```
# Create a new conda environment
conda create -n camodreamer python=3.8.0
conda activate camodreamer

# Install other dependencies
pip install kornia==0.7.3 safetensors==0.5.3 soxr==0.3.7 einops==0.3.2
pip install -r requirements.txt
```

## 2.Training preparation
Take the camouflage dataset LAKE-RED as an example:
- Download [LAKE-RED](https://drive.google.com/file/d/1M96ipKc3nVK_Q_LViM6t9UjT8sayRxuZ/view?usp=sharing) dataset. 
- The image embeddings, i.e., `lakered_image_emb.pt`, are obtained via [CLIPmodel.py](https://github.com/fayewong666999/CamoDreamer/tree/main/datasets/camouflage/lakered/train/CLIPmodel.py) based on DINOv2.
- The foreground masks and mixed foreground-background images, i.e., `masks_fg` and `mix_fg_ori`, are generated by [CLIPmodel.py](https://github.com/fayewong666999/CamoDreamer/tree/main/datasets/camouflage/lakered/train/masks.py) under the corresponding folders, respectively.
- **Note:** Please make sure to modify the weight paths of **DINOv2** and **CLIP-ViT-Large-Patch14** to your local directories before running.

The final camouflage dataset should be ordered as follow:

## 3. CamoDreamer Inference
Camouflage image generation (Note to modify the checkpoint path and dataset path). The pre-trained weights on the LAKE-RED dataset can be downloaded via the [CamoDreamer (LAKE-RED)](https://drive.google.com/file/d/15gp9Lvt-bnJEsXDSehOIZVLPQlkdgNhs/view?usp=sharing):
```bash
python inference.py --img_patch_path img_patch_path_dir --bg_path bg_path_dir
```
Note: --img_patch_path is not actually used during inference. --bg_path should be set to the path of the LAKE-RED training images.

## 4. Generative Evaluations

### 4.1 Fidelity (FID)

We use [torch-fidelity](https://github.com/toshas/torch-fidelity) to calculate FID and KID:

```bash
pip install torch-fidelity
fidelity --gpu 0 --fid --kid --input1 real_images_dir --input2 synthetic_images_dir
```
The resolution of both the real and synthetic camouflage images is **299x299**.

### 4.2 Using eval.sh
We provide an eval.sh script for batch evaluation. First, specify the result root, the data root, and the GPU ID in the script:
```bash
resultroot="Path to generated results ..."
dataroot="Path to LAKERED_DATASET ..."
GPU_ID="1"

echo ${resultroot}
echo ${GPU_ID}

export CUDA_VISIBLE_DEVICES=${GPU_ID}
destimages=${dataroot}'/COD10K_CAM'
echo ${destimages}

python split_validation_subset.py --src_root ${resultroot}
```
Then run the script:
```bash
sh eval.sh
```
The script evaluates the COD, SOD, SEG, and Overall subsets as follows:
```bash
echo "COD"
datapath=${resultroot}'/image_subset/COD'
fidelity --gpu 0 --kid --fid --input1 ${datapath} --input2 ${destimages}

echo "SOD"
datapath=${resultroot}'/image_subset/SOD'
fidelity --gpu 0 --kid --fid --input1 ${datapath} --input2 ${destimages}

echo "SEG"
datapath=${resultroot}'/image_subset/SEG'
fidelity --gpu 0 --kid --fid --input1 ${datapath} --input2 ${destimages}

echo "Overall"
datapath=${resultroot}'/images'
fidelity --gpu 0 --kid --fid --input1 ${datapath} --input2 ${destimages}
```
